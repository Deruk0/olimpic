# Визитки и запись

В каталоге на главной можно отфильтровать опубликованные визитки по предмету. У каждой визитки есть своя ссылка `/teachers/ID`, ставка за 60 минут и список доступных окон по московскому времени. Оплата проходит напрямую преподавателю.

## Преподаватель

1. В разделе «Моя визитка» заполните предметы, описание и ставку. Сохранение публикует визитку.
2. Добавьте будущие окна по 60 минут. Для смены времени можно убрать свободное окно и добавить новое. При удалении окна его ожидающие заявки отклоняются. Занятые уроками окна скрываются с визитки.
3. Откройте «Заявки на занятия» и подтвердите или отклоните заявку. Подтверждение бронирует окно, отклоняет остальные заявки на это же время и добавляет ученика в ваш список. Запланировать сам урок можно через «Ученики» → «Назначить урок».

## Ученик

Откройте визитку и войдите, если требуется. Выберите окно, при необходимости добавьте комментарий и нажмите «Записаться». Статус появится в разделе «Мои заявки». После подтверждения преподаватель появится в личном профиле в разделе «Мои преподаватели».
