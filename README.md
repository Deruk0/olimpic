# Olimpik

Olimpik — платформа для частных преподавателей и их учеников. В каталоге можно найти преподавателя и записаться на урок. В кабинете есть расписание, библиотека материалов, домашние задания с автопроверкой и встроенные видеоуроки. Telegram напоминает об уроках и дедлайнах и сообщает об оценках. Ученики оплачивают занятия напрямую преподавателю.

Стек проекта — Next.js, React и TypeScript, PostgreSQL и локальный PGlite, Tiptap и KaTeX для материалов, WebRTC для видеосвязи и Telegram Bot API для уведомлений.

## Запуск и сброс демо

1. В Windows с Node.js 22 или новее запустите [start.bat](start.bat). Он установит зависимости при необходимости, заполнит локальную базу `data/local-lms` и откроет [страницу входа](http://127.0.0.1:3000/login). Закрытие терминала останавливает сервер.
2. Для Telegram добавьте строку `TELEGRAM_BOT_TOKEN=ваш_токен` в файл `.env.local` в корне проекта и перезапустите приложение. Без токена сайт работает с отключёнными уведомлениями.
3. Перед защитой закройте окно сервера и выполните в PowerShell из корня проекта `.\start.bat --reset-demo`. Команда сохранит предыдущую базу в `data/local-lms-backup-*`, создаст чистую демо-базу и запустит приложение. После сброса войдите заново и повторите привязку Telegram, если хотите показать уведомления.

## Чек-лист показа жюри

1. **Подготовка.** Сбросьте базу, откройте два профиля браузера, приготовьте JPG или PNG решения. Войдите как преподаватель математики и Анна. Для Telegram привяжите Анну через «Профиль» → «Telegram» → `/start КОД` и заранее проверьте кнопку тестового уведомления.
2. **Вступление.** Объясните, почему частному преподавателю и ученику приходится вести уроки, материалы и дедлайны в разных приложениях.
3. **Каталог и запись.** Выйдите из аккаунта Анны, откройте [каталог](http://127.0.0.1:3000/), выберите «Математика» и визитку Марии. Покажите ставку и свободные окна. Войдите с визитки как Дина, подайте заявку, подтвердите её в кабинете Марии и покажите Дину в списке учеников. Затем войдите снова как Анна.
4. **Библиотека и расписание.** Покажите конструктор формул в редакторе задачи и шаблон «ОГЭ · Смешанное ДЗ». В расписании покажите «Демо · Видеоурок» и форму назначения занятия.
5. **Домашнее задание.** Анна открывает уже выданное смешанное ДЗ, выбирает «Один», вводит `2.5` и загружает фото. Покажите два автоматических балла и статус «На проверке». Мария оценивает фото на 2 балла и оставляет комментарий. У Анны появляются итог 4/4 и комментарий в кабинете, а при подключённом Telegram — уведомление.
6. **Видеоурок.** В обоих профилях откройте «Демо · Видеоурок». Покажите звук, демонстрацию экрана и отправку скриншота в чат. Переключите вкладку у Анны и покажите, как у преподавателя меняется индикатор и растёт счётчик. Для звука на одном ПК используйте наушники.
7. **Завершение.** Вернитесь к задаче проекта и назовите один следующий шаг, например совместную доску для разбора задач.

## Разработка

Для ручного запуска выполните `npm ci`, `npm run seed` и `npm run dev`. По умолчанию используется PGlite в `data/olimpik-lms`. Переменная `DATABASE_URL` включает PostgreSQL. `npm run typecheck` проверяет типы, `npm run build` собирает приложение, `npm start` запускает сборку.

Политика `experimental.agentUpgrade: "security"` в `next.config.ts` включает напоминания Next.js об исправлениях безопасности. Чтобы подготовить обновление, выполните `npx next upgrade --agent=security`.
