# Olimpik

Учебная платформа по олимпиадной математике для 8–9 классов. В демонстрационной программе есть диагностика и по три занятия на базовом и продвинутом уровнях.

- **Ученик** смотрит расписание и материалы, сдаёт работы и отслеживает прогресс.
- **Куратор** ведёт расписание группы, отмечает посещаемость, проверяет работы и назначает учебные траектории.
- **Методист** собирает программы, ведёт библиотеку материалов и планирует занятия для групп.

Стек проекта — Next.js, React, TypeScript, Tiptap и PostgreSQL.

## Локальный запуск

Требуется Node.js 22 или новее.

```sh
npm ci
npm run seed
npm run dev
```

Откройте [127.0.0.1:3000](http://127.0.0.1:3000). Команда `seed` создаёт демогруппу, добавляет отсутствующие черновики программ и печатает одноразовые коды в формате `ID: код`. Повторный запуск выдаёт новые коды и сохраняет учебные данные. Храните коды как пароли.

Для быстрого показа вместо `seed` выполните `npm run manage -- demo`. Команда публикует ещё не опубликованные демопрограммы, добавляет пример занятия и печатает многоразовые коды ученика, куратора и методиста на 30 дней. Повторный вызов заменяет многоразовые коды. Используйте отдельную базу с демоданными.

## Возможности

В конструкторе методиста у занятия отдельные редакторы теории, практики, домашней и самостоятельной работы. Можно сохранить неполный черновик и посмотреть раздел глазами ученика. Публикация проверяет обязательные поля. Уже назначенные занятия сохраняют свою версию материалов.

В теории доступны текст, определение, разбор примера и внешняя ссылка. В практике можно добавить раскрываемые подсказки и разбор для самопроверки. У домашней работы можно задать срок в днях от начала занятия. После срока сдача остаётся доступной. У самостоятельной работы задаются рекомендуемое время и порог прохождения. Критерии проверки доступны куратору.

Куратор открывает занятие из расписания, чтобы поменять время, длительность, формат, ссылку на запись или отметить посещаемость. Ученик переходит к теории и работам по отдельным ссылкам из карточки. В разделе «Учебные работы» можно отфильтровать работы по типу и статусу. Каждая работа сдаётся и проверяется отдельно.

## База данных и сборка

| Переменная | Назначение |
| --- | --- |
| `DATABASE_URL` | Строка подключения к PostgreSQL. Без неё используется встроенный PGlite. |
| `OLIMPIK_DATA_DIR` | Каталог PGlite. По умолчанию `data/postgres`. |
| `OLIMPIK_SECURE_COOKIES` | Установите `true` при размещении за HTTPS-прокси. |

Перед запуском служебных команд на том же каталоге PGlite остановите сервер. CLI читает переменные из окружения процесса. Если настройки заданы в `.env.local`, передайте их явно через `node --env-file=.env.local scripts/manage.mjs <команда>`.

Для запуска собранного приложения выполните `npm run build`, затем `npm start`. Для проверки типов используйте `npm run typecheck`.

## Показ комиссии

В разделе «Библиотека» методист отдельно создаёт теорию и задачи, затем собирает из задач практику, домашнюю или самостоятельную работу. В «Расписании групп» он выбирает группу, дату, готовую теорию и нужные работы. Куратор группы получает занятие в своём расписании вместе с материалами для проведения.

Назначение сохраняет снимок материалов. Правки в библиотеке применяются к будущему занятию, когда методист явно выбирает новую версию в расписании. Менять материалы можно до начала занятия и до первой сдачи. Ученик, открывший предыдущую версию задания, получит сообщение при попытке отправить решение и сможет загрузить его после обновления страницы.

1. Выполните `npm run seed` на отдельной демобазе. В отдельных профилях браузера войдите по выданным кодам для `methodist`, `curator`, `anna` и `boris`. Для повторного входа выпустите новый код командой `npm run manage -- invite ID`.
2. Методист открывает вкладки «Базовый», «Продвинутый» и «Диагностика», проверяет материалы и публикует каждую программу.
3. Куратор добавляет диагностику в расписание группы. Анна и Борис подтверждают цель, открывают диагностику в разделе «Учебные работы» и прикрепляют по PDF или фото к каждому заданию.
4. Куратор ставит Анне 2, 4, 2 балла, Борису — 5, 4, 5 баллов. На вкладке «Траектории» появляются рекомендации базового и продвинутого уровней. Куратор меняет порядок тем, назначает сроки и публикует планы.
5. Куратор добавляет одно занятие базового уровня. Анна открывает конспект и ссылку на встречу, сдаёт практику и проверочную работу. Куратор выставляет баллы и комментирует, Анна видит обратную связь и обновлённый прогресс. Методист видит сводку группы и может отправить рекомендацию куратору.

## Новая группа

```sh
npm run manage -- account curator2 curator "Имя куратора"
npm run manage -- group group2 "Набор 8–9 классы" curator2
npm run manage -- account student1 student "Имя ученика" group2
```

Команда `npm run manage -- invite ID` выдаёт новый одноразовый код для существующего аккаунта. Коды действуют 7 дней, сессии — 14 дней. Время расписания вводится по Москве.
